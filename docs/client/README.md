# Cliente Eaglercraft

Esta pasta é o ponto de integração do cliente web compilado.

Não há um cliente distribuído aqui por padrão: adicione somente um build que você tenha
permissão para redistribuir e siga a licença do projeto de origem. A página `game.html` mantém
um sandbox independente até que o cliente seja conectado.

Consulte o `README.md` na raiz para o checklist de integração e de deploy.
